## Overview

Xenomorph is a dual-microcontroller ESP32-based framework for Wi-Fi security research:

- **Muscle (ESP32 - ESP-IDF v4.1.4)**: The attack engine implementing evil twin attacks, deauthentication frames, packet sniffing, WPA handshake capture, rogue AP functionality, and channel hopping. Based on the original [esp32-wifi-penetration-tool](https://github.com/risinek/esp32-wifi-penetration-tool) by [@risinek](https://github.com/risinek).
- **Commander (ESP32-S3 - Arduino IDE v2.3.8)**: The UI frontend with OLED 128x64 display, 5-button navigation (UP/DOWN/LEFT/PUSH/RIGHT), and UART interface to control the Muscle firmware.

The two components communicate via a custom UART protocol called **Xeno Protocol v3.0** (115200 baud, XOR checksum framed).

This framework was developed as a Final Project / Academic Research for the Computer Engineering Technology program, focusing on network virtualization security and embedded system orchestration

## Main Features

### Wi-Fi Attack Methods Supported

| Feature | Description |
|---------|-------------|
| **Evil Twin / Rogue AP** | Creates a fake AP with cloned SSID & BSSID from the target, captive portal to capture credentials |
| **Deauth Attack** | Deauthentication at 30 fps (v4.0 improvement from 1 fps) to disconnect clients from the real AP |
| **Disassociation** | Different frame type than deauth, effective against some client drivers |
| **WPA Handshake Capture** | Captures 4-way handshake via passive, broadcast, or rogue AP methods |
| **Packet Sniffing** | Promiscuous mode capture on specific channel, export to PCAP format |
| **Probe Request Monitoring** | Monitors client probe requests, tracking unique SSIDs in the area |
| **Network Join** | ESP32 joins as STA to target network (v4.0 new feature) |

### Capture Export Formats

| Format | Usage |
|--------|-------|
| **PCAP** (.pcap) | libpcap format compatible with Wireshark |
| **HCCAPX** (.hccapx) | Hashcat-ready format for WPA2 password cracking |

### Download Portal:
Unified HTTP server at Management IP (`192.168.4.1`) with a launcher page containing two cards for downloading PCAP and HCCAPX files.

> **Note:** PMKID capture feature has been disabled in this repository. Implementation exists in `attack_pmkid.c` but is not integrated into the main workflow.

## Build & Flash Instructions

### 1. Build Firmware Muscle (ESP-IDF v4.1.4)

Prerequisites: [ESP-IDF v4.1.4](https://docs.espressif.com/projects/esp-idf/en/v4.1.4/) installed.

```bash
cd <project-root>
idf.py set-target esp32
idf.py build
idf.py flash -p <PORT>      # Replace COMx (Windows) or /dev/ttyUSB0 (Linux/Mac)
idf.py monitor
```

>  Build time varies depending on your computer's specifications. Binary output: `build/esp32/.../firmware.bin`.

### 2. Build Firmware Commander (Arduino IDE v2.3.8)

- Open `xenomorph_commander_s3/xenomorph_commander_s3.ino` in Arduino IDE v2.3.8
- Select board **ESP32S3 Dev Module** (or appropriate hardware)
- Serial port: match connected device
- Click **Upload**

## Wiring & First Boot

UART wiring must be **cross-over**:

| Commander (ESP32-S3) | → | Muscle (ESP32) | Function |
|---|---|---|---|
| GPIO 43 (TX) | → | GPIO 16 (RX) | Commander TX to Muscle RX |
| GPIO 44 (RX) | ← | GPIO 17 (TX) | Commander RX from Muscle TX |
| GND | ↔ | GND | Common ground |

- Power both devices separately (5V each)
- Commander shows "Online" on OLED
- Muscle serial log shows `"Muscle READY v4.0"`
- Connect phone/appliance to ManagementAP: SSID `ManagementAP`, password `mgmtadmin`
- Open browser: `http://192.168.4.1/` → Download page loads
